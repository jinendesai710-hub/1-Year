# Images

Drop the 10 anniversary photos into this folder using these exact filenames
(referenced by `words.js`):

- `photo-1.jpg`
- `photo-2.jpg`
- `photo-3.jpg`
- `photo-4.jpg`
- `photo-5.jpg`
- `photo-6.jpg`
- `photo-7.jpg`
- `photo-8.jpg`
- `photo-9.jpg`
- `photo-10.jpg`

The reveal view will display whatever image is found at each path. If an image
is missing, the gradient placeholder behind the photo frame will still show.
For best results, use landscape-oriented photos around 1200x900px (4:3) or
larger. JPG, PNG, and WebP are all supported.
